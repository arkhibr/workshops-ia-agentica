# S2 — O ambiente agêntico — ferramentas e fluxo

**Bloco:** 1 — Fundamentos

## Problema

Cada desenvolvedor usa uma ferramenta diferente, do próprio jeito, sem fluxo compartilhado com o resto do time.

## Intenção metodológica

Fluxos reutilizáveis como metodologia codificada, não como preferência individual. Isolamento de contexto por ramo de trabalho e gerência explícita do que entra na janela de contexto do agente — a cadeia de ferramentas é agnóstica (Claude Code + Codex CLI, GitHub Copilot + VS Code/JetBrains, ou Cursor IDE), mas o método é o mesmo nas três.

## Ao final desta sessão, o participante consegue

Configurar o ambiente agêntico escolhido pela equipe e rodar um ciclo completo de entrada → resposta → verificação.

## Exercício

Configurar o ambiente e rodar um ciclo entrada → resposta → verificação de ponta a ponta.
