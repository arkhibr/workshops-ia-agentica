# S6 — TDD assistido por IA

**Bloco:** 3 — Execução

## Problema

Aceitar código gerado sem uma rede de testes que confirme o comportamento é aceitar código no escuro — e o agente também erra.

## Intenção metodológica

O ciclo vermelho → verde → refatoração conduzido com um LLM, com o teste funcionando como especificação executável. xUnit para C#, Jest para JavaScript/TypeScript. Parte do exercício é justamente detectar quando o agente erra — seja na implementação, seja no próprio teste que ele mesmo escreveu.

## Ao final desta sessão, o participante consegue

Aplicar TDD assistido por IA em uma funcionalidade nova, incluindo a verificação crítica de que o teste gerado realmente falha antes de passar.
