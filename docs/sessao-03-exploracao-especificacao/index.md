# S3 — Exploração e especificação

**Bloco:** 2 — Especificação e Planejamento

## Problema

Pedidos vagos ao agente produzem código que compila mas não faz o que o time realmente precisava — a ambiguidade migra do requisito para o código gerado.

## Intenção metodológica

O ciclo explorar → perguntar → propor → especificar, com requisitos formalizados no padrão BR (regra de negócio) / FR (requisito funcional) / NFR (requisito não funcional). A especificação como contrato entre humano e agente: o que está escrito é o que será construído, nem mais nem menos.

## Ao final desta sessão, o participante consegue

Escrever uma especificação no padrão BR/FR/NFR que um agente consegue seguir sem interpretação livre.
