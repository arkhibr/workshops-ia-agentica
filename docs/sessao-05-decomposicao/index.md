# S5 — Decomposição — planos para SDD

**Bloco:** 2 — Especificação e Planejamento

## Problema

Uma especificação correta ainda pode virar uma tarefa grande demais para o agente executar sem interação — sem decomposição, o humano perde o controle do que está sendo construído.

## Intenção metodológica

Distinção entre tarefa atômica e tarefa composta, com critério de aceitação por tarefa e pontos de controle explícitos. O plano é a unidade de controle humano sobre a execução do agente — não uma formalidade, mas o que garante que o humano intervém no momento certo, e não só no fim.

## Ao final desta sessão, o participante consegue

Decompor uma especificação em um plano de tarefas atômicas, com critérios de aceitação, pronto para execução por SDD.
